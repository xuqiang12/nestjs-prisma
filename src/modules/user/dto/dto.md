# NestJS + Prisma + MySQL DTO 装饰器速查表

> 适用场景：NestJS 后端开发 + Prisma ORM + MySQL  
> 核心依赖：class-validator、class-transformer、@nestjs/swagger  
> 可直接复制到项目文档中，开发时快速查阅

## 一、最常用装饰器（95% 场景必用）

| 装饰器                 | 作用                                         | 适用场景                                            |
| :--------------------- | :------------------------------------------- | :-------------------------------------------------- |
| @IsNotEmpty()          | 标记为必填项，不能为 null/undefined          | 所有非可选字段（如用户名、邮箱）                    |
| @IsString()            | 校验字段必须是字符串类型                     | 用户名、标题、描述、备注等                          |
| @IsInt()               | 校验字段必须是整数                           | Prisma 中 Int 类型（ID、数量、年龄等）              |
| @IsNumber()            | 校验字段必须是数字（含小数）                 | Prisma 中 Float 类型（价格、评分等）                |
| @IsBoolean()           | 校验字段必须是布尔值（true/false）           | 状态开关（如 isActive、isDelete）                   |
| @Length(min, max)      | 限制字符串长度（min 最小长度，max 最大长度） | 用户名（2-20 位）、密码（6-20 位）、标题（2-50 位） |
| @Min(num)              | 限制数字最小值                               | 价格 ≥0、年龄 ≥0、页码 ≥1                           |
| @Max(num)              | 限制数字最大值                               | 年龄 ≤150、页大小 ≤100                              |
| @Type(() => Number)    | 将前端传入的字符串参数转为数字               | URL 查询参数（如 id=1、page=1）                     |
| @ApiProperty()         | 定义接口文档中必填字段的描述、示例           | 配合 Swagger 生成接口文档（必填字段）               |
| @ApiPropertyOptional() | 定义接口文档中可选字段的描述、示例           | 配合 Swagger 生成接口文档（非必填字段）             |

## 二、常用装饰器（进阶/特殊场景）

| 装饰器                          | 作用                                  | 适用场景                                          |
| :------------------------------ | :------------------------------------ | :------------------------------------------------ |
| @IsOptional()                   | 标记为可选字段，允许为 null/undefined | 更新接口的非必填字段（如修改年龄、备注）          |
| @IsEmail()                      | 验证字段格式为合法邮箱                | 登录、注册时的邮箱字段                            |
| @IsUrl()                        | 验证字段格式为合法 URL                | 图片链接、第三方跳转链接、官网地址                |
| @IsUUID()                       | 验证字段格式为合法 UUID               | Prisma 中主键为 UUID 的场景                       |
| @Matches(/regExp/)              | 自定义正则表达式校验                  | 手机号、身份证号、特殊密码规则（如含大小写+符号） |
| @IsEnum(EnumObj)                | 验证字段值必须是指定枚举中的值        | 状态码（如 StatusEnum）、性别（如 GenderEnum）    |
| @IsArray()                      | 校验字段必须是数组类型                | 批量操作入参（如批量删除的 id 列表）              |
| @ArrayMinSize(num)              | 限制数组最小长度                      | 确保数组至少有一个元素（如批量操作至少选一个）    |
| @ArrayUnique()                  | 确保数组中所有元素唯一                | ID 列表、标签列表（避免重复）                     |
| @ValidateNested({ each: true }) | 校验嵌套对象/数组中的嵌套对象         | 复杂 JSON 结构、关联对象入参                      |
| @IsDate()                       | 校验字段必须是合法日期格式            | 时间相关字段（如 createdAt、endTime）             |
| @IsJSON()                       | 验证字段为合法 JSON 字符串            | 存储 JSON 格式的字段（如 extraInfo）              |
| @Allow()                        | 允许字段为任意值，不做校验            | 动态字段、预留扩展字段                            |
